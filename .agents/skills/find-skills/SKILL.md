# Find Skills

This skill helps discover and install skills from the open agent skills ecosystem.

## When to Use

Use this skill when asking to search, discover, or install new agent skills, tools, or workflows.

## Key CLI Commands

- `npx skills find [query]` - Search for skills by keyword
- `npx skills add <package>` - Install a skill from GitHub or ecosystem
- `npx skills update` - Update all installed skills

Browse available skills online at: https://skills.sh/
