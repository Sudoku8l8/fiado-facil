# Frontend Design

Approach UI building as a senior product designer delivering distinctive, premium, production-grade visual identities.

## Design Guidelines & Principles

### 1. Visual Identity & Aesthetic Direction
- Avoid generic AI templated looks (plain white backgrounds with standard blue buttons).
- Establish an opinionated color palette tailored to the brand domain (use CSS HSL/variables for light/dark themes).
- Pair display and body typography intentionally (e.g., modern Google Fonts like Outfit, Inter, Plus Jakarta Sans, or Roboto).

### 2. Layout & Typography
- Create clear contrast and visual hierarchy through font weights, scale, line heights, and spacing.
- Ensure structural elements (borders, dividers, eyebrows, badges) convey meaningful information rather than pure visual noise.

### 3. Motion & Micro-interactions
- Incorporate subtle hover effects, active states, and transition animations for buttons, cards, and interactive elements.
- Keep animations purposeful, smooth, and performant (CSS transitions/transforms).

### 4. Component Refinement & Polish
- Use modern UI patterns like glassmorphism, subtle card elevations/shadows, rounded borders, and rich gradient highlights.
